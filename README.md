# Rocket Propagation Simulation

## Project Overview
A Python-based simulation project to study and visualize rocket motion and its physical behavior.

## Objectives
- Simulate rocket flight and trajectory.
- Calculate altitude, velocity, and acceleration.
- Visualize simulation results using plots.
- Analyze the effect of different simulation parameters.

## Tools and Technologies
- Python
- Google Colab
- NumPy
- Matplotlib
